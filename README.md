# NotchKat releases

Signed and notarised NotchKat disk images, and the update feed NotchKat checks.

- Downloads: [Releases](https://github.com/HendrikK/notchkat-releases/releases)
- Update feed: `https://hendrikk.github.io/notchkat-releases/appcast.xml` (served from this repository by GitHub Pages)

This repository is written by `scripts/publish-update.sh` in the NotchKat repository. Don't edit `appcast.xml` by hand: every entry is signed.
